# ChickenFarm real-footage studio

Independent production for @chicken.farm107. No generated animal imagery. No credentials in this public repository. Run Actions > Real footage pilot to download verified Wikimedia footage, render vertical MP4s, and retrieve the artifact. Review the video, captions, audio and attribution before scheduling. This pilot does not publish to TikTok. Do not rerun it as new content or use the other channel's credentials. The publishing connection must be authorized separately.

Sources: Nesnad, CC BY 4.0, and Uusijani, CC0 1.0; source URLs and change notices are included in the export.
